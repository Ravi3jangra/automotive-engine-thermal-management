# Automotive Engine Thermal Management System (ECU Design)

## Overview
Designed an automotive engine thermal management system using MATLAB/Simulink and Stateflow to regulate engine temperature under varying operating conditions.

## Features
- Closed-loop thermal control system
- Stateflow-based finite state machine (FSM)
- Multi-level fan control (OFF, MEDIUM, HIGH)
- Temperature-based decision logic

## Technologies Used
- MATLAB
- Simulink
- Stateflow

## Working
- Engine temperature is continuously monitored
- FSM determines system state based on temperature thresholds
- Fan speed adjusts dynamically to maintain optimal temperature

## Control Strategy
- Closed-loop feedback system
- Multi-state logic using FSM
- Designed for stability and fast response

## Output
- Temperature vs time graph
- Stable thermal behavior
- Smooth transitions between states

## Applications
- Automotive ECU systems
- Engine thermal control
